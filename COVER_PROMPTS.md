# 홈케어랩 기사 표지 — 실사 사진 프롬프트 (62편)

## 사용법
1. 아래 프롬프트를 이미지 AI(DALL·E 3 / Midjourney / Adobe Firefly 등)에 **그대로 붙여넣기**
2. 나온 이미지를 **가로 1200px(16:9) JPG**로 저장 → 파일명은 각 항목의 `파일명` 그대로
3. `public/images/covers/` 폴더에 넣고 알려주면 → 기사 표지 + 홈 썸네일 + 공유(OG) 이미지로 자동 연결
4. **일관성 팁**: 한 세션에서 같은 설정으로 쭉 뽑기 / Midjourney는 첫 컷의 `--sref`·`--seed` 재사용 / DALL·E는 스타일 문장 고정

> 모든 프롬프트는 동일한 "밝고 미니멀한 인테리어 매거진 사진" 톤 + 민트 포인트로 통일돼 있어, 사이트 전체가 한 결로 보입니다.
