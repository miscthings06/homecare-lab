아래는 **홈케어랩 메인페이지 와이어프레임 v1.0**입니다.
방향은 **“홈서비스 플랫폼처럼 보이되, 실제로는 애드센스 승인에 유리한 정보형 비용 가이드 사이트”**입니다.

국내 레퍼런스에서는 미소처럼 청소·이사·가전렌탈·인터넷을 한 생활서비스 묶음으로 보여주는 구조를 참고하고, 클린벨처럼 입주청소·이사청소·에어컨청소·세탁기청소 등 구체 서비스와 견적 비교 흐름을 참고하면 좋습니다. 미소는 생활청소, 이사·입주청소, 인터넷 가입, 가전렌탈을 주요 서비스로 묶고 있고, 클린벨은 입주이사청소·원룸이사청소·세탁기청소·에어컨청소와 지역별 시세·견적 비교를 전면에 둡니다. ([대한민국 1등 홈서비스 - 미소][1])

# 홈케어랩 메인페이지 핵심 방향

## 메인페이지 목적

홈케어랩의 첫 화면은 “상담 신청 사이트”가 아니라 아래처럼 보여야 합니다.

> **청소비용, 가전렌탈, 이사준비, 생활비 절감을 비교해주는 홈서비스 정보 가이드**

이렇게 해야 애드센스 승인 전에는 정보성 사이트로 보이고, 승인 후에는 아정당·청소·렌탈·이사·인터넷 제휴 CTA를 자연스럽게 붙일 수 있습니다.

구글 애드센스는 사이트 승인 관점에서 **고유한 콘텐츠, 방문자와 관련 있는 내용, 명확하고 사용하기 쉬운 내비게이션, 좋은 사용자 경험**을 요구합니다. 따라서 홈 화면은 “광고 배너”보다 “카테고리 탐색, 비용 가이드, 체크리스트, 계산기” 중심이어야 합니다. ([Google 도움말][2])

## 실제 문구

### 설명문

* 청소비용 확인하기
* 가전렌탈 비교하기
* 이사준비 체크하기

Angi와 HomeAdvisor는 비용 가이드 글에서 평균 비용, 비용 범위, 집 크기, 추가 서비스 같은 판단 기준을 먼저 보여주고, 이후 견적 CTA로 연결합니다. 홈케어랩도 메인에서 바로 “견적 신청”이 아니라 “비용 기준 확인”을 먼저 보여주는 것이 안전합니다. ([Angi][3])

# 3. 청소비용 가이드 섹션

## 와이어프레임

```text
┌──────────────────────────────────────────────────────────────┐
│ H2. 청소비용, 왜 집마다 다를까요?                            │
│ 설명: 평수, 오염도, 청소 범위에 따라 실제 비용이 달라집니다. │
│                                                              │
│ ┌──────────────────────────┐ ┌──────────────────────────┐   │
│ │ 입주청소 비용 기준        │ │ 이사청소와 입주청소 차이   │   │
│ │ 평수별 비용 확인          │ │ 공실 상태와 짐 유무 차이   │   │
│ └──────────────────────────┘ └──────────────────────────┘   │
│ ┌──────────────────────────┐ ┌──────────────────────────┐   │
│ │ 에어컨 청소 비용          │ │ 세탁기 청소 비용           │   │
│ │ 셀프·업체 차이            │ │ 통돌이·드럼 차이           │   │
│ └──────────────────────────┘ └──────────────────────────┘   │
└──────────────────────────────────────────────────────────────┘
```

## 섹션 문구

### H2

**청소비용, 왜 집마다 다를까요?**

### 설명

입주청소와 이사청소는 평수만으로 비용이 정해지지 않습니다.
오염도, 창틀·베란다 포함 여부, 주방 기름때, 곰팡이, 가전청소 추가 여부에 따라 실제 비용이 달라질 수 있습니다.

### 카드 구성

* 입주청소 비용 기준
* 이사청소와 입주청소 차이
* 에어컨 청소 셀프 vs 업체
* 세탁기 청소가 필요한 증상

## 승인 후 전환

승인 전 버튼:

* 비용 기준 보기
* 청소 범위 확인하기

승인 후 버튼:

* 입주청소 견적 비교하기
* 에어컨 청소 견적 확인하기

단, 승인 전에는 “견적 비교하기” 버튼을 메인에 노출하지 않는 편이 좋습니다.

청소비와 렌탈비는 한 번의 선택으로 차이가 나고, 전기요금과 난방비는 매달 누적됩니다.
집에서 반복적으로 나가는 비용을 항목별로 점검해보세요.

## 카드 구성

* 에어컨 전기요금 계산법
* 보일러 난방비 줄이는 설정
* 대기전력 차단 효과
* 에너지바우처 확인 방법
* 고효율가전 환급 확인 방법

이 섹션은 애드센스 승인에 중요합니다. 제휴성 콘텐츠만 있으면 사이트가 얇아 보일 수 있으므로, 생활비 절감 정보가 정보성 균형을 잡아줍니다.

# 8. “견적 전 체크리스트” 섹션

## 와이어프레임

```text
┌──────────────────────────────────────────────────────────────┐
│ H2. 업체를 고르기 전, 이것만은 확인하세요                     │
│                                                              │
│ □ 기본 청소 범위가 어디까지인지 확인했나요?                   │
│ □ 창틀, 베란다, 주방 후드, 곰팡이 제거가 포함되나요?          │
│ □ 추가요금이 붙는 조건을 확인했나요?                          │
│ □ 예약 취소·변경 기준을 확인했나요?                           │
│ □ 후기에서 시간약속·AS 대응을 확인했나요?                     │
│                                                              │
│ [청소 견적 전 체크리스트 보기]                                │
└──────────────────────────────────────────────────────────────┘
```

## 적용 이유

클린벨은 고객후기, 업체 랭킹, 지역별 시세, 추가요금 관련 콘텐츠를 함께 보여줍니다. 홈케어랩도 “업체 추천”보다 “업체 선택 전 확인해야 할 기준”을 제시해야 정보성 사이트로 보입니다. ([클린벨][6])

# 9. 최신 글·가이드 섹션

## 와이어프레임

```text
┌──────────────────────────────────────────────────────────────┐
│ H2. 최근 업데이트된 홈케어 가이드                             │

│ │ 인터넷 이전 설치 신청 전  │ │ 에어컨 청소 셀프와 업체    │   │
```

* 생활비절감 글 1개

이렇게 보여줘야 사이트 주제가 한쪽으로 쏠리지 않습니다.

# 10. 승인 후 제휴 CTA 전환 섹션

승인 전에는 이 섹션을 숨기거나, 아주 약하게 정보형으로 둡니다.

## 승인 전 버전

```text
┌──────────────────────────────────────────────────────────────┐
│ H2. 우리집 조건에 맞는 선택 기준을 먼저 확인하세요            │
│                                                              │
│ 청소, 렌탈, 인터넷 이전은 집의 상태와 사용 기간에 따라        │
│ 유리한 선택이 달라질 수 있습니다.                             │
│                                                              │
│ [비용 비교 가이드 보기] [체크리스트 보기]                     │
└──────────────────────────────────────────────────────────────┘
```

## 승인 후 버전

```text
┌──────────────────────────────────────────────────────────────┐
│ H2. 청소·렌탈·인터넷, 조건별로 비교해보세요                   │
│                                                              │
│ 입주청소, 가전렌탈, 인터넷 이전은 조건에 따라 비용과 혜택이   │
│ 달라질 수 있습니다. 여러 조건을 비교한 뒤 선택하세요.         │
│                                                              │
│ [청소 견적 비교하기] [가전렌탈 조건 비교하기] [인터넷 이전 확인]│
└──────────────────────────────────────────────────────────────┘
```

아정당은 인터넷, 가전렌탈, 이사, 청소 카테고리를 모두 갖고 있으므로 승인 후 CTA 연결에는 적합합니다. 다만 승인 전에는 아정당 브랜드를 전면에 두기보다 “조건 비교” 흐름으로 유지하는 편이 안전합니다. ([아정당][4])

승인 전부터 하단 고정 버튼을 “상담 신청”으로 두면 광고성 사이트처럼 보일 수 있으므로, 초기에는 **비용 계산하기 / 체크리스트**가 더 좋습니다.

# 홈케어랩 메인페이지 실제 문구 초안

아래 문구를 그대로 메인페이지에 쓸 수 있습니다.

## 메인 타이틀

**청소부터 가전렌탈까지, 우리집 생활비 줄이는 홈서비스 가이드**

## 서브 문구

입주청소, 이사청소, 정수기 렌탈, 인터넷 이전 설치까지
우리집 상황에 따라 비용이 달라지는 기준을 쉽게 비교해보세요.

## 섹션 문구

### 지금 어떤 정보가 필요하세요?

집 상태, 이사 일정, 렌탈 기간에 따라 필요한 정보가 달라집니다.
가장 먼저 확인해야 할 항목부터 선택해보세요.

### 청소비용, 왜 집마다 다를까요?

청소비용은 평수만으로 정해지지 않습니다.
오염도, 청소 범위, 창틀·베란다 포함 여부, 곰팡이 제거, 가전청소 추가 여부에 따라 실제 비용이 달라질 수 있습니다.

### 가전렌탈, 구매보다 유리한 경우가 있을까요?

정수기, 공기청정기, 비데, 건조기 렌탈은 월 렌탈료만 보고 판단하면 안 됩니다.
약정기간, 관리주기, 필터 교체 조건, 해지 비용까지 함께 비교해야 합니다.

### 이사 전후, 무엇부터 준비해야 할까요?

이사 준비는 청소, 인터넷 이전, 도시가스, 폐가전, 렌탈 이전을 따로 보면 놓치는 항목이 생깁니다.
날짜별로 필요한 홈서비스를 한 번에 정리해보세요.

### 매달 새는 생활비도 함께 줄여보세요

청소비와 렌탈비는 한 번의 선택으로 차이가 나고, 전기요금과 난방비는 매달 누적됩니다.
집에서 반복적으로 나가는 비용을 항목별로 점검해보세요.
