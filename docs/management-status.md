- 홈페이지에 사이트 목적을 설명하는 고유 H1 추가

- 검색 노출이 확인된 청소 글과 방문 흔적이 있는 렌탈 비용 글 4편에 공식 출처와 출처 적용 범위 추가

## 애드센스 재신청 전 핵심 위험

### 1. 모든 상세 글에 노출되던 사이드바 제휴 버튼

상세 글 62편의 사이드바에 아정당 외부 버튼이 공통 노출되고 있었다. 순수 정보성 글도 제휴 페이지처럼 보이게 하는 요소이므로 2026-07-16에 승인 전 단계에서 제거했다. 본문 하단의 문맥상 필요한 제휴 버튼만 제한적으로 유지한다.

추가로 전환 의도가 약한 상세 글 18편에서 본문 제휴 버튼과 상단 제휴 문구를 제거했다. 상세 글 중 제휴 링크가 있는 페이지는 28편에서 핵심 10편으로 축소했다. 홈페이지와 계산기에는 각각 문맥에 맞는 제휴 고지를 유지한다.

### 2. 공식 출처가 표시된 글의 비율

상세 글 62편 중 `ArticleInfoCard`에 공식 출처를 직접 표시한 글은 17편이다. 비용·요금·지원제도·약정 등 검증 가능한 주제부터 공식 출처와 확인일을 확대해야 한다. 출처 수만 늘리는 것이 아니라, 본문의 핵심 수치가 어느 자료에 근거하는지 연결해야 한다.

### 3. 운영자와 저자 신뢰 정보

현재 저자는 `닥터 홈케어`라는 필명으로 표시되며 실명, 실제 경력, 취재·검증 사례가 없다. 확인되지 않은 경력은 추가하지 않는다. 운영자가 공개 가능한 범위의 실제 소개, 사이트를 운영하게 된 구체적 경험, 직접 만든 사진·견적 비교·검증 기록을 확보한 뒤 소개 페이지를 보강한다.

### 4. 원본 경험과 고유 자료 부족

글 수와 분량은 부족하지 않지만 다수 글이 같은 형식의 비용표·체크리스트·CTA로 구성되어 있다. 재신청 전에는 새 글 대량 발행보다 다음 원본 자료를 우선한다.

- 실제 견적서 또는 상담 결과를 개인정보 제거 후 범위 데이터로 정리
- 직접 촬영한 청소 전후 사진이나 설치 조건 사진
- 지역·평형·제품 조건별 자체 비교표와 계산 근거
- 기존 글의 핵심 수치를 공식 자료와 다시 대조한 수정 기록

### 5. 루트 도메인 중복 응답 — 조치 완료

2026-08-07 Cloudflare 단일 리디렉션을 배포하여 `https://homecare-lab.co.kr/*`를 경로와 쿼리 문자열을 유지한 `https://www.homecare-lab.co.kr/*`로 301 이동하도록 조치했다.

## 재신청 순서

1. 애드센스 거절 화면의 정확한 사유 문구와 날짜 확보
2. 운영자 소개에 넣을 수 있는 실제 정보와 원본 자료 범위 확정
3. 검색 유입 또는 핵심 주제 글 15~20편을 우선 선정
4. 선정 글마다 핵심 수치 출처, 계산 과정, 직접 판단 기준, 수정일 보강
5. 상업성 높은 CTA는 핵심 전환 글 하단으로만 제한
6. Cloudflare에서 루트 도메인 301 리디렉션 설정 — 완료
7. Search Console 소유권 인증 및 사이트맵 상태 확인 — 완료. 색인·실적 데이터 처리 후 재점검
8. 수정 내용 배포 후 크롤링과 색인 반영을 확인하고 재신청

재신청은 단순 문구 수정만으로 진행하지 않는다. Google의 승인 안내는 사이트 전체 페이지를 검토할 수 있으며, 독창적이고 풍부한 콘텐츠가 부족한 사이트와 충분한 추가 가치가 없는 제휴 콘텐츠를 품질 문제로 설명한다. 기준 문서: <https://support.google.com/adsense/answer/81904?hl=en>

## 변경 원칙

- 근거 없는 실명·경력·체험담·후기는 만들지 않는다.
- 글 수를 늘리는 것보다 기존 핵심 글의 실제 가치와 검증 가능성을 높인다.
- 외부 제휴 버튼은 정보 흐름을 방해하지 않도록 하단에 제한한다.
- 요금·지원제도처럼 변동 가능한 정보는 확인일과 공식 출처를 함께 갱신한다.
- 배포 전 `npm.cmd run build`로 전체 빌드를 확인한다.
